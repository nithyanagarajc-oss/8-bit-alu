# 8-Bit ALU Using Verilog

## Aim

To design and simulate an 8-bit Arithmetic Logic Unit (ALU) using Verilog HDL.

## Description

An ALU is a digital circuit that performs arithmetic and logical operations on binary data.

This project implements an 8-bit ALU that accepts two 8-bit inputs, `A` and `B`, and performs different operations based on the 3-bit `ALU_Sel` control signal.

The ALU supports:

* Addition
* Subtraction
* AND
* OR
* XOR
* NOT

## Inputs

| Signal    |  Size | Description         |
| --------- | ----: | ------------------- |
| `A`       | 8-bit | First input         |
| `B`       | 8-bit | Second input        |
| `ALU_Sel` | 3-bit | Operation selection |

## Outputs

| Signal   |  Size | Description              |
| -------- | ----: | ------------------------ |
| `Result` | 8-bit | ALU operation result     |
| `Carry`  | 1-bit | Carry output             |
| `Zero`   | 1-bit | Indicates result is zero |

## ALU Operation Table

| ALU_Sel | Operation | Description |
| ------- | --------- | ----------- |
| `000`   | ADD       | A + B       |
| `001`   | SUB       | A - B       |
| `010`   | AND       | A & B       |
| `011`   | OR        | A | B       |
| `100`   | XOR       | A ^ B       |
| `101`   | NOT       | ~A          |

## Example Operations

### Addition

```text
A = 25
B = 15

25 + 15 = 40

Result = 8'h28
```

### Subtraction

```text
A = 25
B = 15

25 - 15 = 10

Result = 8'h0A
```

### AND

```text
A = F0
B = 0F

F0 & 0F = 00
```

### OR

```text
A = F0
B = 0F

F0 | 0F = FF
```

### XOR

```text
A = F0
B = 0F

F0 ^ 0F = FF
```

### NOT

```text
A = 55

~55 = AA
```
